# Halo

שלוש טבעות ליום אחד: **מיקוד**, **משימות** ו**נשימה**. אפליקציית ווב בעברית בהשראת אפל, עם זכוכית נוזלית, רקע אורורה חי וארבע ערכות צבעים.

## מה יש בפנים

- **היום:** טבעות התקדמות, תצוגת שבוע, רצף ימים ורשימת משימות
- **מיקוד:** טיימר של 15, 25 או 50 דקות שממשיך לרוץ גם אחרי רענון
- **נשימה:** כדור מונחה בשלוש תבניות (ריבוע, 4-7-8, קוהרנטי)
- **הגדרות:** צבעים, מצב כהה או בהיר, ויעדים יומיים
- **באייפון:** אפשר להוסיף למסך הבית. נפתחת במסך מלא ועובדת גם בלי אינטרנט

הנתונים נשמרים רק בדפדפן שלך (`localStorage`). אין שרת, אין חשבון ואין מעקב.

## הרצה מקומית

בלי התקנות ובלי build:

```bash
python3 -m http.server 4599
```

ואז לפתוח את http://localhost:4599
